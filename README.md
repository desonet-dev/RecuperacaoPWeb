# RecuperacaoPWeb
Projeto construído em React com base no protótipo fornecido em sala de aula para entrega da recuperação obrigatória da matéria de Programação Web III, referente ao 3ºBimestre. O objetivo principal é avaliar a capacidade de produção de um sistema com design profissional e responsivo, além da funcionalidade de troca de tela utilizando a biblioteca React Router.
